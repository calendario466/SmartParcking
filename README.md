# SmartParking — Operación Estacionamiento

Aplicación de escritorio para administrar espacios, clientes, vehículos, registros de estacionamiento y pagos de SmartParking.
El caso aplica abstracción, encapsulamiento, herencia y polimorfismo, con arquitectura MVC y persistencia en JSON.

## Ejecutar
Requiere Python 3.12 o superior. Desde la carpeta del repositorio:

```bash
python -m src.smartparking
```
